# Fitmeezo Mobile App (Flutter)

## Overview
This folder is reserved as a placeholder for the future **Fitmeezo Android/iOS mobile application**, which will be developed using Flutter in a planned subsequent phase.

## Architecture Notes
- The mobile app will consume the exact same Django backend and PostgreSQL database via the Django REST Framework (DRF) APIs established in `backend/`.
- Authentication, product catalog, cart, orders, and payment webhooks will be shared between the web storefront and this mobile application.

## Development Status
- **Current Phase**: Phase 1 (Foundation)
- **Status**: Reserved / Pending Flutter App Phase (see `docs/PROJECT_PLAN.md`)
